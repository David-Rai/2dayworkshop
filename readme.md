## 📚 Syllabus

Our comprehensive 2-day workshop covers the fundamentals of web development and provides hands-on experience for beginners. 

**Full Syllabus Details Link:** 
🔗 [View Detailed Syllabus on Notion](https://app.notion.com/p/Basic-Web-Development-2-Day-3c34f5435a56800e8120e6aad9c1bae0?source=copy_link)

### Overview:
- **Day 1:** Introduction to HTML5, fundamental concepts, structuring a webpage, and an introduction to CSS and responsive design concepts.
- **Day 2:** Introduction to JavaScript, working with variables, basic DOM manipulation, adding website interactivity, and showcasing final mini-projects.

## 👥 Participants Showcase

We had an amazing turnout with a **total count of 35+ participants** actively engaging in learning and building their own web applications!

Check out the impressive work designed and coded by our students over just 2 days. The raw source code is stored safely under the `./student_projects` directory in this repository and is deployed to the live participants' pages.

## 🛠️ Tech Stack & Workshop Contents

- **HTML5:** Semantic architecture
- **CSS:** Tailwind CSS & Vanilla CSS layout designs
- **JavaScript:** Custom scripting and DOM manipulations
- **Node.js (build script):** Automatically fetches student projects from directories
